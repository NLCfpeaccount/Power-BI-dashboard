# Indian Flight Route Analysis ✈️🇮🇳

An interactive **Power BI Dashboard** providing deep insights into the Indian aviation landscape, focusing on route efficiency, carrier performance, and passenger trends.

## 📌 Project Overview
This dashboard analyzes domestic flight data across India to identify high-traffic corridors, pricing fluctuations, and airline reliability. It serves as a strategic tool for understanding the connectivity between major Indian hubs and Tier-2 cities.



## 📊 Key Insights & Features
* **Route Traffic Analysis:** Visualizing the busiest routes (e.g., Delhi-Mumbai, Bangalore-Delhi) using flow maps.
* **Airline Performance:** Comparison of market share and on-time performance among carriers like IndiGo, Air India, and Vistara.
* **Pricing Trends:** Analysis of fare fluctuations based on booking windows and seasonal demand.
* **Airport Connectivity:** Heatmaps showing the density of flights across different Indian states.
* **Delayed vs. On-Time:** Breakdowns of delay reasons and frequency across various time slots.

## 📈 DAX Highlights
I implemented several custom measures to enhance the analytical depth, such as:
* **Occupancy Rate %**: Calculating the load factor per flight.
* **Route Profitability Index**: A custom formula weighing flight frequency against average ticket price.
